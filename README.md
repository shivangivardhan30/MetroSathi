# MetroSathi

AI-Based Metro Navigation System for all metro networks across India.

## Features

- Online metro ticket booking (placeholder flow)
- Nearest station discovery from current location
- Station entry/exit gate guidance
- Platform and train direction assistance
- AI assistant for instant travel questions
- Live journey tracking and arrival alerts
- Multi-city metro network support
- Hindi and English interface support

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Open http://localhost:3000 in your browser.

## Project Structure

- `pages/` — app pages and API routes
- `components/` — reusable UI components
- `styles/` — global styles

## Notes

This starter app includes core navigation UI, language switching, and AI assistant placeholders to help build MetroSathi further.
